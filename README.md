## About TrustVault

TrustVault is a secure document-sharing platform designed to help organizations manage and share confidential documents with authorized users. The platform provides secure authentication, role-based access control, document preview and download, instant access revocation, and tamper-evident audit trails.

### Key Features

- **Secure Authentication:** Protects access to the platform through user authentication.
- **Role-Based Access Control:** Ensures users can access only the documents and features permitted by their assigned roles.
- **Secure Document Sharing:** Enables organizations to share confidential documents with authorized users.
- **Document Management:** Supports uploading, organizing, previewing, and downloading documents.
- **Instant Access Revocation:** Allows document access permissions to be revoked when necessary.
- **Tamper-Evident Audit Trails:** Uses hash-chain verification to help detect unauthorized changes to audit records.

### Project Objective

The objective of TrustVault is to improve the confidentiality, integrity, and accountability of organizational document sharing through secure access management and verifiable activity records.
